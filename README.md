# Portafolio de Joan Enrique Chavarría Peraza

Portafolio personal con proyectos individuales de desarrollo web: PawsConnect, ASEMUC Convenios, Cementerio Bernabela y TalentBridge.

## Tecnologías

HTML y CSS. JavaScript mínimo para el año del pie de página. Diseño adaptable, navegación por secciones y detalles de proyectos desplegables. Tipografías de Google Fonts con fuentes alternativas del sistema.

## Vista local

Abrí `index.html` en el navegador. También podés servir la carpeta con cualquier servidor HTTP estático.

## Desplegar en Vercel

1. Importá `JoaChP/portafolio-joan` desde tu cuenta de Vercel.
2. Framework Preset: **Other**.
3. Root Directory: raíz del repositorio.
4. No requiere instalación ni comando de compilación. `vercel.json` configura la salida estática.
5. Desplegá. No requiere variables de entorno.

Los siguientes cambios en `main` se publican automáticamente si la integración de GitHub está conectada.

## Contenido

Las ilustraciones son composiciones conceptuales hechas con CSS, no capturas de las aplicaciones. TalentBridge se identifica como prototipo con datos simulados. Los enlaces externos abren las demos y los repositorios correspondientes.
